# PRANA · mockup

Maqueta visual de la tienda en línea de PRANA. Es un prototipo de diseño con datos de ejemplo, no el sitio final.

- `index.html` · página de inicio con carrito, filtros, buscador y popup de ejemplo.
- `admin.html` · vista de ejemplo del panel de administración.
- `img/` · aquí van las fotos. Los nombres que usa la página están en `img/LEEME.txt`.

## Cambiar las fotos

1. Copia tus imágenes a la carpeta `img/` con los nombres de `img/LEEME.txt` (por ejemplo `escena-1.jpg`, `producto-1.jpg`).
2. Sube los cambios a GitHub. La página se actualiza sola en uno o dos minutos.
